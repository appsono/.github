# Sono

**Welcome to Sono!**
It's a music platform built around **local music playback**

Built with Flutter. The new version does not include any tracking software.*

---

### Projects

#### sono-new *(active)*
Flutter mobile app for local music playback. This is the primary project and main focus of development.

#### sono-mobile *(archived)*
Previous version of the mobile app. No longer maintained.

---

### Supporting Projects

#### sono_query
Custom Flutter package for querying local music on device.

#### sono-api
FastAPI backend used by the mobile and web apps.

---

*No Google Crashlytics or Google Analytics.
